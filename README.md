# Campos Brasileiros para WooCommerce — CPF, CNPJ e CEP com validação

Adiciona ao checkout do WooCommerce os **campos brasileiros** que faltam — **CPF**, **CNPJ**, Razão Social, RG, Inscrição Estadual, número e bairro — com validação de verdade.

**Instale pelo diretório de plugins do WordPress:**
→ https://wordpress.org/plugins/rebel-studios-brazilian-checkout-fields/

Plugin gratuito (GPLv2) da [Rebel Studios](https://rebelstudiossoftware.com).

## O que faz

- **Valida CPF e CNPJ pelo dígito verificador** — não só pela máscara, então um número inválido não passa.
- **Preenche o endereço pelo CEP** automaticamente.
- Grava os dados **no pedido e na API**, onde o seu ERP ou nota fiscal consegue ler.
